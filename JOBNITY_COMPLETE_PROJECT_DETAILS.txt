1. EXECUTIVE SUMMARY & PROBLEM FORMULATION
================================================================================
Jobnity is an intelligent, privacy-first career acceleration and technical
readiness engine designed to bridge the structural disconnect between candidate
resumes, industry role requirements, and technical interview evaluations.

Traditional hiring platforms and Applicant Tracking Systems (ATS) suffer from:
1. Keyword Bloat & False Positives: Surface-level keyword matching counts
   occurrences of terms without validating depth of applied usage, tenure, or
   project context.
2. Static & Vague Job Descriptions: Candidates lack actionable clarity regarding
   the precise technical gaps separating their existing profile from target roles.
3. Disconnected Mock Interviews: Generic interview prep tools ask generic trivia
   questions (e.g., standard LeetCode or textbook definitions) rather than
   evaluating candidates against the actual technologies, architectures, and
   trade-offs claimed on their resumes.

Jobnity resolves these bottlenecks by combining deterministic NLP parsing,
mathematical skill gap scoring, and grounded local Large Language Model (LLM)
inference. The platform extracts verifiable proof-of-work from candidate resumes,
maps them against 60+ standardized industry benchmark roles, quantifies exact
skill deficits, delivers personalized week-by-week learning roadmaps, and
conducts an adaptive technical interview that specifically probes the
candidate's declared projects and technologies.

2.1 SENSING / INGESTION MODULE
------------------------------
- Purpose: Ingest, validate, clean, and segment raw candidate resume files.
- Ingestion Gateway: Handles multipart HTTP uploads of PDF and DOCX files.
- Validation Guardrails: Magic byte inspection (%PDF- for PDF, PK\x03\x04 for
  DOCX), file size caps (<10MB), and corruption detection.
- Multi-Tier Cascading Extractor:
  * Tier 1: High-throughput PyPDF2 stream parser for text-native PDFs.
  * Tier 2: Layout-aware pdfplumber parser for multi-column and table layouts.
  * Tier 3: python-docx XML parser for Microsoft Word documents.
- Text Normalization Pipeline: Deduplicates extraneous whitespace, repairs
  typographical ligatures (fi, fl, ae), and cleans non-printable Unicode characters.
- ATS Boundary Segmenter: Deterministic regex-based state machine that segments
  raw text into canonical structural zones: Summary, Experience, Education,
  Skills, and Projects.
- Modular Ingestion Adapter (BaseIngestionAdapter): Standardized interface enabling
  future plugins for cloud object storage (AWS S3, Cloudflare R2), OCR engines
  (Tesseract), or enterprise ATS integrations (Workday, Greenhouse).

2.2 PROCESSING / ANALYTICAL MODULE
----------------------------------
- Purpose: Execute entity extraction, evidence scoring, role matching, gap
  quantification, and LLM-driven interview evaluation.
- NLP Extractor: Heuristic entity recognizer for Candidate Name, Email, Phone,
  Degree, Institution, Graduation Year, and Work Experience tenure.
- Contextual Evidence Extractor: Evaluates where each skill appears in the resume:
  Experience (Weight 5) > Certifications (Weight 4) > Projects (Weight 3) >
  Education (Weight 2) > Unsubstantiated Skill List (Weight 1).
  Maps evidence to a 6-tier proficiency scale (L0: None to L5: Advanced Master).
- Semantic Role Recommender: Computes n-gram TF-IDF representations of candidate
  evidence against benchmark job roles, using cosine distance to produce
  ranked match tiers: Strong Fit (>80%), Moderate Fit (65-80%), and High Potential.
- Multi-Factor Skill Gap Scorer: Evaluates required vs. preferred competencies,
  below-level proficiencies, and transferable skills via a closed-form formula.
- Grounded Adaptive LLM Evaluator: Powered by a local Qwen 2.5 (3B/7B) model.
  Generates personalized technical questions grounded directly in the candidate's
  verified resume projects, and scores candidate answers across Relevance (35%),
  Technical Correctness (40%), and Clarity/Structure (25%).
- Pluggable Analytical Bus (BaseAnalyticalAdapter): Decoupled interface allowing
  zero-downtime hot-swapping between Ollama (Qwen 2.5), HuggingFace Transformers,
  vLLM, or proprietary enterprise endpoints.

2.3 STORAGE / PERSISTENCE MODULE
--------------------------------
- Purpose: Maintain durable relational persistence, session caching, and the
  curated career knowledge graph.
- Engine: Embedded SQLite database (`backend/jobnity.db`) managed via SQLAlchemy 2.0.
- Skill Taxonomy & Ontology: Over 1,000 standardized technical skills with alias
  normalization (e.g., 'k8s' -> 'kubernetes', 'react.js' -> 'react') and collision
  guardrails (ensuring 'Java' does not accidentally trigger 'JavaScript').
- Benchmark Role Repository: 60+ pre-configured industry job profiles complete
  with required skills, preferred skills, minimum proficiency thresholds, and
  seniority benchmarks (Junior, Mid, Senior, Lead).
- Learning Resource Catalog: Hundreds of curated, verified educational resources
  (official documentation, hands-on labs, interactive sandboxes, video deep dives)
  mapped directly to specific skill deficit IDs.
- Interview & Rubric History: Durable logging of interview sessions, individual
  generated questions, candidate transcript responses, and rubric breakdowns.

2.4 VISUALIZATION & CLIENT INTERACTION MODULE
--------------------------------------------
- Purpose: Deliver a polished, ultra-responsive, accessible user interface.
- Core Architecture: Single Page Application (SPA) built with React 18, Vite,
  and React Router v6.
- Motion & Ergonomics: Integrated Lenis kinetic smooth scrolling and Framer

- Visual Gap Diagnostics: Interactive SVG radar charts and stacked horizontal

6. CORE ALGORITHMS, MATHEMATICAL FORMULATIONS & PROMPT PIPELINES
================================================================================

6.1 EVIDENCE EXTRACTION & PROFICIENCY CLASSIFICATION (L0-L5)
------------------------------------------------------------
Candidate skill claims are not treated equally. An empirical weight function
W(section) assigns proof-of-work credibility:
- W(Production Work Experience) = 5
- W(Verified Industry Certifications) = 4
- W(Shipped Independent Projects) = 3
- W(Academic Coursework / Education) = 2
- W(Isolated Skills List / Header Keyword) = 1

For each skill s in document sections {sec_i}:
  Cumulative Evidence Score E(s) = SUM[ W(sec_i) * (1 + 0.15 * TenureMonths) ]

Mapping to Canonical Proficiency Matrix:
- L0 (None): E(s) = 0 (No mentions detected)
- L1 (Basic Familiarity): 1 <= E(s) < 4 (Listed in skill inventory or coursework)
- L2 (Working Knowledge): 4 <= E(s) < 9 (Used in academic or hobby projects)
- L3 (Proficient): 9 <= E(s) < 18 (Applied in production or major capstone)
- L4 (Advanced): 18 <= E(s) < 30 (Multiple production deployments, 24+ months)
- L5 (Subject Matter Expert): E(s) >= 30 (Architectural leadership, 36+ months)

6.2 SEMANTIC ROLE MATCHING (TF-IDF & COSINE SIMILARITY)
-------------------------------------------------------
Candidate extracted profile text T_cand is normalized, lowercased, and converted
into an n-gram TF-IDF vector v_cand:
  v_cand = TfidfVectorizer(ngram_range=(1, 2), stop_words='english').fit_transform(T_cand)

Each standardized role j in the job catalog has a benchmark vector v_role_j:
  Cosine Similarity S_cos(cand, role_j) = (v_cand . v_role_j) / (||v_cand|| * ||v_role_j||)

The match score is calibrated across hard competency thresholds to yield tiers:
- Strong Fit: S_cos >= 0.80 AND Core Coverage >= 75%
- Moderate Fit: 0.65 <= S_cos < 0.80
- High Potential: S_cos < 0.65 with high transferable skill overlap

6.3 MULTI-FACTOR SKILL GAP & READINESS SCORING FORMULATION
----------------------------------------------------------
The final Readiness Index Score R in [0, 100] is calculated via:

  R = 0.55 * C_req + 0.25 * P_align + 0.10 * E_qual + 0.10 * C_pref + B_trans

Where:
- C_req (Core Required Coverage):
    C_req = ( Count of required skills where Level_cand >= Level_req ) / ( Total Required Skills ) * 100
- P_align (Proficiency Depth Alignment):
    P_align = ( 1 / N ) * SUM[ min(1.0, Level_cand(k) / Level_req(k)) ] * 100
- E_qual (Evidence Quality Factor):
    Normalized aggregate of proof-of-work weights across verified skills.
- C_pref (Preferred / Secondary Skill Coverage):
    Coverage of nice-to-have competencies that differentiate candidates.
- B_trans (Transferable Skill Bonus):
    Up to 5.0 bonus points awarded when candidate possesses equivalent technologies
    (e.g., strong PostgreSQL proficiency compensating for MariaDB requirement).

6.4 GROUNDED ADAPTIVE INTERVIEW QUESTION GENERATION PIPELINE
------------------------------------------------------------
To eliminate LLM hallucination and ensure strict relevance, the interview prompt
in `backend/app/services/llm_service.py` is injected with real resume evidence:

SYSTEM PROMPT:
"You are a Senior Technical Hiring Lead conducting an in-depth technical interview.
You must STRICTLY GROUND every question in the candidate's real resume projects,
technologies, and claimed proficiency levels.
DO NOT ask generic trivia. Ask real-world architectural, operational, or trade-off
questions that verify whether the candidate truly built what they claimed.
Ensure questions adhere to the STAR framework (Situation, Task, Action, Result)."

6.5 MULTI-AXIS STAR RUBRIC EVALUATION ENGINE
--------------------------------------------
When the candidate submits an answer, Qwen 2.5 evaluates the transcript:
- Relevance (Weight 35%): Did the candidate answer the specific question asked,
  referencing real technical mechanics rather than generic platitudes?
- Technical Correctness (Weight 40%): Are the architectural concepts, code patterns,
  and trade-offs technically accurate according to industry best practices?
- Clarity & Structure (Weight 25%): Did the candidate present their thoughts
  methodically, adhering to Situation-Task-Action-Result structure?

Composite Answer Score = (0.35 * Relevance + 0.40 * Correctness + 0.25 * Clarity) * 10

7. END-TO-END USER JOURNEY & APPLICATION WORKFLOW
================================================================================
The user interacts with Jobnity through a seamless, 5-phase guided journey:

7.1 STEP 1: RESUME UPLOAD & INGESTION GATE (`/analyse-resume`)
- Candidate drags & drops a PDF or DOCX resume, or clicks one of three pre-loaded
  sample industry profiles (Software Engineer, Data Scientist, Cloud Engineer).
- Backend executes multi-tier text extraction, ATS boundary segmentation, and
  entity recognition within 250 milliseconds.

7.2 STEP 2: EXTRACTED PROFILE REVIEW & VERIFICATION
- Candidate reviews parsed contact details, extracted education, and categorized
  skills organized into clean tags (Languages, Frameworks, Tools, Cloud).
- Candidate has the ability to adjust proficiency ratings or add omitted
  credentials before committing to analysis.

7.3 STEP 3: ROLE RECOMMENDATION & TARGET SELECTION
- The system presents AI-recommended target job profiles ranked by compatibility.
- Each card displays Match Score, Key Candidate Strengths, Missing Skills, and
  a concise rationale explaining the fit.
- Candidate selects their target ambition (e.g., "Full Stack Engineer").

7.4 STEP 4: MULTI-AXIS SKILL GAP ANALYSIS & READINESS REPORT
- Interactive visual diagnostic dashboard renders:
  * Readiness Score Gauge (e.g., 84% - Job Ready).
  * Category Breakdown (Core Coverage, Proficiency Alignment, Evidence Quality).
  * Matched vs. Deficit Skills Breakdown with direct remediation paths.
  * Two primary call-to-actions: "Practice Technical Interview" or "Explore Roadmaps".

7.5 STRUCTURED CAREER ROADMAPS (`/roadmaps`)
- Interactive 8-week curriculum mapped specifically to the candidate's deficits.
- Features milestone check-offs, practical capstone project specifications,
  and direct outbound links to official documentation and interactive labs.

7.6 AI MOCK INTERVIEW SIMULATION (`/interview`)
- Interactive, terminal-inspired simulation.
- Generates 3 progressive, highly personalized technical questions grounded
  in the candidate's actual projects.
- Live progress indicator (Question 1 of 3, Question 2 of 3, Complete).
- Real-time feedback modal displaying composite scores, STAR alignment,
  key technical strengths, and actionable remediation tips.

7.7 TECHNICAL DOCUMENTATION & ARCHITECTURE PORTAL (`/docs`)
- Self-contained, tabbed documentation suite detailing Tech Stack, Backend
  Pipelines, Frontend Architecture, and Algorithmic Formulations.

9. SECURITY, PRIVACY & LOCAL INFERENCE GUARANTEES
================================================================================
1. Zero Data Egress: All parsing, evidence extraction, vector similarity, and
   LLM question generation occur 100% locally on the host machine.
2. Confidentiality of Candidate Data: Resume documents and candidate PII never
   traverse external commercial AI APIs (no OpenAI, Anthropic, or third-party cloud).
3. Payload & File Guardrails: Binary magic byte checking prevents arbitrary code
   execution or malicious payload injection disguised as documents.
4. Ephemeral & Isolated Processing: Document uploads are processed in isolated
   memory streams, with disk persistence restricted to local encrypted SQLite storage.
